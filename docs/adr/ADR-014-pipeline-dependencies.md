# ADR-014 파이프라인 파이썬 의존성

## 상태
승인 (2026-08-04, 결정자: 이윤서)

## 맥락
- `pipeline/`이 실물로 서기 시작하면서(M-01) 파이썬 런타임과 의존성을 확정해야 한다.
- CLAUDE.md § Agent Behavior: **의존성 추가는 근거를 대고 먼저 묻는다.** 승인 시 ADR 한 줄을 남긴다.
- 3주 MVP·1인 개발이므로 "직접 구현 대신 검증된 라이브러리"가 기본값이되, 개수는 최소로 간다.

## 결정 — 4종만 쓴다

| 패키지 | 버전 | 왜 불가피한가 |
|---|---|---|
| `pandas` | 3.0.5 | 원본이 전부 표(CSV)다. 인코딩 폴백·충전율 감사·격자 조인이 전부 DataFrame 연산 |
| `pyproj` | 3.7.2 | ADR-008 §7이 EPSG:4326↔5179 **명시 변환**을 요구한다. 좌표계 변환을 손으로 구현하는 것은 함정 제조 |
| `geopandas` | 1.1.4 | SGIS 경계가 SHP(EPSG:5179)로만 온다. GeoJSON 산출·시연 시군구 클리핑까지 같은 라이브러리로 처리 (`shapely` 동반 설치) |
| `pytest` | 9.1.1 | ADR-009 결정 1의 pipeline 테스트 2종(함정 재현·seed 검증)이 이미 요구하고 있다 |

**Python 3.13**으로 고정한다. 로컬 기본이 3.14였으나 geopandas 휠이 아직 없다 — 실측 확인 후 3.13 venv로 내렸다.

```bash
python3.13 -m venv .venv && ./.venv/bin/pip install -r pipeline/requirements.txt
```

`.venv/`·`__pycache__/`·`.pytest_cache/`는 `.gitignore` 대상. 버전은 `requirements.txt`에 **핀 고정**한다 —
발표 시연 재현성이 최우선이고, 이 프로젝트의 모든 인용 수치는 재현 가능한 실측이어야 한다.

## 기각한 대안
- **`pyshp`로 geopandas 회피** — 의존성은 1개 줄지만 공간 클리핑·좌표 변환·GeoJSON 직렬화를 손으로 짜야 한다. 함정이 늘어나는 방향이라 기각.
- **`chardet` 인코딩 자동 감지** — 표본에 따라 결과가 흔들려 재현성이 깨진다. ADR-008 §1이 이미 금지.
- **`scikit-learn` 등 ML 스택** — v0 랭킹은 수식으로 나온다. 커밋 9(LTR)에 실제로 착수할 때 별도 ADR로 판단한다.
- **`requests`** — 표제부·지오코딩 호출은 표준 `urllib.request`로 충분하다. 호출부가 복잡해지면 재론한다.

## 결과 (트레이드오프 수용)
- `geopandas`는 GDAL 계열 바이너리를 끌고 와 설치가 무겁다 — 휠로 해결되는 범위라 수용.
- Python 3.13 고정은 로컬 기본(3.14)과 어긋난다. `requirements.txt` 상단에 이유를 주석으로 박아 다음 사람이 헤매지 않게 한다.
