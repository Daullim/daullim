## 검수 실측 (7항목)

1. **인코딩 — 파일마다 다르다.** 플랫폼 상품(476·462) = UTF-8-SIG / 소방청 전국 파일·SGIS 전체 = cp949. `read_csv_kr()` 경유 필수.
2. **파일명 정규화 혼재.** fire·SGIS = NFD, call119 = NFC. NFC 정규화 없이 glob/grep 하면 조용히 빠진다(이번 검수 중 2회 실제 발생).
3. **행수.** 화재 2023: 서울 5,671 / 부산 2,468 / 전북 2,167. 신고 2023: 서울 2,030,921 / 부산 896,935 / 전북 613,682 — PoC 실측 범위(서울 193만~212만/년 등) 재현.
4. **필드 충전율 편차.** 출동지령·현장도착 시각(`DSPT_DRTV_DT`·`GRNDS_ARVL_DT`)은 **전북만 44.1%·39.0%, 서울·부산 0%**. `CTY_FRMVL_SE_NM`: 화재 상품 100% / 신고 상품 서울 97.5%·부산 ~65%·전북 59.6%. `GRID_ID` 충전(신고): 서울 77.5%·부산 65.1%·전북 58.7%.
5. **SGIS 구성.** 1km 확정. long 포맷(기준연도·격자코드·통계항목·통계값). 필요 지표 전부 존재: `in_grp_008`(고령)·`ga_sd_005`(1인가구)·`ho_gb_001~006`(주택유형)·`ho_yr_001~020`(건축년도)·`to_in_001`(총인구). 항목 코드 정의는 `sgis/3. 코드집/2. 제공용 코드(statistics_code).xlsx`. 서울(다사) `to_in_001` = 7,008셀 — 정의서 실측과 일치.
6. **값 범위 이상 — 습도·적설 스왑이 2023 화재 상품에 실존.** `HR_UNIT_HUM` 0.1~17(충전 ~3%) ↔ `HR_UNIT_SNWFL` 7~100(충전 ~100%)로 분포가 뒤바뀜. `validate_ranges()` fail-fast 대상.
7. **좌표 결측률(화재 상품 LAT/LOT).** 서울 0.44% / 부산 0.24% / 전북 2.63% — 결측분은 읍면동 상향 집계.

## 지역 코드 체계 3종 (2026-08-04 실측)

같은 시군구를 가리키는 코드가 출처마다 다르고, **에러가 아니라 빈 결과나 엉뚱한 지역으로 응답.**

| 시연 지역 | ① 통계청(SGIS) | ② 행정표준(법정동) | ③ 격자 존 |
|---|---|---|---|
| 서울 관악구 | `11210` | `11620` | `다사` |
| 전북 임실군 | `35550` | `52750` | `다마` |
| 부산 기장군 | `21510` | `26710` | `마라`, `마마` |
| 부산 부산진구 | `21050` | `26230` | `마라` |

- **서울만 시도 2자리가 우연히 일치(`11`)한다.** 부산은 `21`(①) vs `26`(②), 전북은 `35`(①) vs `52`(②).
  서울로 테스트하면 통과하고 전북에서 깨지는 전형적 패턴이라, 시연 구성(관악+임실)이 정확히 이 함정을 밟는다.
- **더 교묘한 건 ①의 부산 `21`이 ②에도 존재한다는 점** — 폐지된 '부산직할시'다. "없는 코드"가 아니라 "폐지된 코드"에 맞아 들어간다.
  2026-08-10 부산 2곳이 편입되면서 이 함정이 **가정이 아니라 실제 시연 경로**가 됐다.
- **기장군만 격자 존이 둘이다**(`마라`+`마마`). 시군구가 100km 존 경계에 걸치는 유일한 사례라
  `zone[0]` 고정이 실제로 깨진다 — `pipeline/README.md` § 규칙 셋의 `resolve_grid500()` 참조.
- **전북은 2024-01-18 전북특별자치도 출범으로 `45`(전라북도, 폐지) → `52`(존재)로 바뀌었다.** 임실군도 `45750` → **`52750`**.
  구 코드로 API를 부르면 `totalCount: 0`이 정상 응답으로 돌아온다.
- 사용처: ① SGIS 격자 통계(도농 판별·$V^\perp$) / ② 건축HUB `sigunguCd`·`bjdongCd`, **DB `buildings.sigungu_cd`** / ③ 화재·신고 `GRID_ID`, SGIS 경계.

**법정동 ≠ 행정동이라는 축이 하나 더 있다.** 건축HUB는 `bjdongCd`(법정동)만 주는데
`buildings.admin_dong_cd`는 행정동 NOT NULL이다. 관악구는 법정동 3개(봉천·신림·남현)에 행정동 21개라 역산이 불가능하다.
→ VWorld 도로명 검색 응답의 `level4AC`(행정동코드)를 좌표와 함께 받아 채운다(추가 호출 0).

**대응:** 코드는 유틸 한 곳에서 체계명을 명시해 꺼내 쓰고(`_4326`/`_5179` 접미사 규약과 동형),
조인은 코드 대 코드가 아니라 좌표 → EPSG:5179 500m 공통 셀 키로 하며,
행정표준코드 자리에 통계청 코드가 들어오면 fail-fast 시킨다.

시연 지역 법정동 수(= 표제부 API 순회 단위): **관악구 3개 / 임실군 143개**(읍면 12 + 리 131) /
**기장군 67개**(읍면 5 + 리 62) / **부산진구 11개**. 리 레벨이 있는 곳은 리만 순회한다(중복 수집 방지).
