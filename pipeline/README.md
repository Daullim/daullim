# pipeline — 배치 추론 파이프라인 (M-01 / M-01b)

원본 데이터 → 검증 → 도농 판별 → 점수 → `seed/buildings.csv`·`units.csv`·GeoJSON → DB 적재.
**산출물은 `buildings` 테이블의 행임.**

## 셋업

```bash
python3.13 -m venv .venv && ./.venv/bin/pip install -r requirements.txt
```

Python 3.13 고정(3.14는 geopandas 휠 미비). 근거는 [ADR-014](../docs/adr/ADR-014-pipeline-dependencies.md).

## 테스트

```bash
./.venv/bin/python -m pytest
```

법정동코드(`data/codes/`)가 없으면 관련 테스트는 skip된다 — 원본 배치는 [data/README.md](../data/README.md) 참조.

## 규칙 셋 (어기면 조용히 틀린 답이 나온다)

- **인코딩을 추측하지 않는다.** `read_csv_kr()`이 UTF-8-SIG → cp949 순으로만 시도한다. `chardet` 금지.
- **비교·조인 전에 NFC.** 원본 파일명이 NFD와 NFC로 섞여 있어 표준 `glob`이 조용히 0건을 낸다 → `glob_kr()`.
- **범위 검사와 충전율 리포트는 한 쌍이다.** 습도·적설 스왑은 범위 검사를 **통과한다**. 충전율 비대칭이 실제 탐지 수단.
- **격자는 코드 대 코드로 붙이지 않는다.** 좌표 → `cell_key()`(EPSG:5179, 500m 스냅)가 정본 경로.
  `grid500_to_1km()`은 문자열 유도 경로이며, 두 경로를 **자체 대조**해서 쓴다.
- **시군구 코드는 체계를 명시해서만 꺼낸다.** `sigungu_code("imsil", "mois")` — 인자 없이 못 꺼내게 막아 뒀다.
- **코드 검증은 "존재"가 아니라 "현행"으로 한다.** 폐지 코드가 실존해서 통과해 버리는 케이스가 있다(부산 `21` = 폐지된 부산직할시).
- **원인이 다른 손실을 한 숫자로 합치지 않는다.** '격자 미부여'(→읍면동 상향 집계)와 '시도 경계 밖'(→클리핑)은
  후속 처리가 다르다. 합치면 클리핑이 실제로 한 일을 알 수 없다. 연도별 건수도 마찬가지로
  **분류 정책 드리프트와 격자 커버리지 드리프트를 나란히** 낸다 — 아래 실측이 그 이유다.

## 검증된 실측 (재현 가능)

- `grid500_to_1km` — 서울 2023 화재 **5,646/5,646 = 100.00%**가 SGIS 경계 격자에 적중.
  ⚠️ 대조 상대는 경계 SHP(8,609셀)여야 한다. 인구통계(7,008셀)로 대조하면 9셀이 빠지는데,
  그건 유도 실패가 아니라 **무인구 격자 = NO_POP 신호**다(§2-2의 '비정형 주거 확인 큐' 후보).
- **두 경로 자체 대조(§4-5)** — 좌표 변환 경로와 문자열 유도 경로가 **5,645/5,646 = 99.98%** 같은 셀을 가리킨다.
  불일치 1건은 500m 경계에 정확히 걸친 점의 반올림 차이(`다사45b41b` vs `다사45a41b`)다.
  존 원점은 `가나다라마바사` 인덱스로 유도된다(`zone_origin()`): x = 700000 + i·100000 / y = 1300000 + j·100000.
  실측 6개 존(다사·마라·마마·다마·라마·나마) 전부를 테스트가 잠근다.
- 좌표↔코드 대조를 3개 시도로 확대 — 서울 99.98% · 부산 100.00% · 전북 100.00%.
- `DSPT_REQ_HR`은 **초 단위**다. 서울 평균 355초 ≈ 5.9분으로 정의서 URBAN 실측과 일치 —
  도농 완충대 임계값 420s와 같은 축임이 확인됐다.
- 지역 코드 3종 대조표와 검수 7항목은 [data/README.md](../data/README.md)에 있다.

### v0 성적표 (§7) — 3개 시도 합산, `run_region_type.py`

| 지표 | 실측 | 목표 | |
|---|---|---|---|
| 플랫폼 라벨 일치 URBAN | **879/925 = 95.0%** | 95% | 통과 |
| 플랫폼 라벨 일치 RURAL | **985/1,236 = 79.7%** | 80% | 통과(정의서 값의 반올림 전 수치) |
| 출동소요 단조성 | 6.7 → 7.7 → 12.6 → 13.6분 | 단조 증가 | 통과 |

정의서 인용값(879/925·985/1236·NO_POP 54셀)과 **표본 크기까지 일치**한다. 대조 규약이 핵심이라 못 박아 둔다:

- 유니버스 = **3개 시도 합산**(시도별로 쪼개면 안 된다 — 서울은 읍·면이 없어 RURAL 표본이 성립하지 않는다)
- **저장값 `region_type_cd`가 URBAN/RURAL인 격자만** — BUFFER·NO_POP 제외
- 분모는 **판별 기준**(행 방향). 플랫폼 기준으로 재면 URBAN 75.5%·RURAL 91.3%로 전혀 다른 수가 나온다

**플랫폼 라벨 `CTY_FRMVL_SE_NM`은 밀도가 아니라 행정 구분이다** — 교차표가 100% 결정적이다(동→도시, 읍·면→농촌).
우리 판별은 DEGURBA 밀도 기준이므로 두 지표는 서로 다른 것을 잰다. 불일치 격자를 열어 보면
실제로 인구 116~129명/km²의 저밀도 지역(정분류 도시 격자는 5,245~11,064)이라 **판별이 틀린 게 아니라 축이 다르다.**
100% 일치는 목표가 아니며, 목표를 넘겼다고 해서 두 라벨이 같은 개념이 되는 것도 아니다.

### PoC 인용값과 어긋난 것 (지어내지 않고 그대로 적는다)

- **"미클리핑 시 14배 팽창"은 재현되지 않았다.** 우리 실측은 서울 500m 기준 **1.9배**(2023: 15,623→8,395),
  1km 기준 **3.7배**(5년 누적: 18,987→5,192)다. 클리핑이 필요하다는 결론은 그대로지만 배율은 다르다.
  PoC의 34,037/2,420이 어떤 집계 단위였는지 확인되지 않아 **미재현으로 남긴다.**
- **2021 급증은 시도마다 성격이 다르다.** 부산의 격자 기준 2.65배 증가(229,588→609,102)는
  신고가 늘어서가 아니라 **격자 부여율이 27.4%→65.5%로 뛴 커버리지 변화**다(원본 행수는 838k→938k로 완만).
  반면 **화재 분류 건수의 증가는 실재**한다 — 서울 20,348→31,628(1.55배), 전북 7,872→12,830(1.63배).
  두 드리프트가 겹쳐 있으므로 리포트가 원본 행수와 격자부여율을 나란히 낸다.
- **'활동 있는 침묵' 격자** — 서울 293 · 부산 78 · 전북 322 (5년 누적, 총신고 50+ / 화재신고 0).
  PoC 인용값(265 · 135 · 481)과 같은 규모대이나 **정확히 일치하지는 않는다**(집계 기간·클리핑 기준 차이 추정).
- 화재 상품에는 **시도 경계 밖 행이 0건**이다. 클리핑 함정은 신고 상품에만 있다.
- **NO_POP 승격 대상이 0건이다.** 54셀·화재 59건·사망 2명은 PoC 인용값과 정확히 재현되지만,
  그 59건의 구성은 자동차/철도차량 21 · 기타 19 · 임야 5 · 교육 4 · 산업 4 · 기타서비스 4 · 집합 2로
  **주거화재가 0건**이다. 사망 2명도 차량 화재다(군산 옥서면·진안 상전면).
  §2-2 규칙(`P=0 ∧ 주거화재>0`이면 승격)을 그대로 적용하면 전량 모델 제외가 맞다 —
  구현은 규칙대로 동작한다. 다만 **"통계 부재가 곧 최고 취약의 신호"의 근거로 이 사망 2명을 인용하면 안 된다**(2023 단년 기준).
- **신고 유형별 격자 부여율이 다르다** — 전북 2023 기준 화재 63.2% vs 구급 88.9%(서울은 85.1% vs 93.8%).
  '활동 있는 침묵' 지표가 이 편차에 교란될 수 있다. 화재 신고가 유독 격자를 못 받는 만큼
  '화재 0'이 과대 계상된다는 뜻이라, 해당 격자 수는 **상한으로 읽어야 한다.**
